# Housing-Society-Management-System
📌 Project Overview

The Housing Society Management System is a proposed web-based application for organizing the residential, administrative, financial, and security records of a housing society. It will replace disconnected manual registers with a centralized relational database, allowing authorized society staff to manage houses, owners, tenants, visitors, vehicles, maintenance bills, complaints, employees, facilities, and bookings.

👥 Target Users 

Society Administration: Manages property ownership, lease agreements, operational tracking, and employee assignments.
